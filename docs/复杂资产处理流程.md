# 复杂资产处理流程

复杂资产不得直接进入正式检索层。处理顺序以
`data/staging/beijing-upper/complex_asset_processing_queue.csv` 为准。

## P0：优先处理

P0 包含与居住、公共服务、间距、日照、养老、无障碍、道路和用地分类直接相关的复杂表格与低置信 OCR 页。

1. 表格：使用 PP-StructureV3 或同类表格结构模型提取 HTML/二维单元格。
2. 使用 Qwen3-VL 对照原图检查表头、合并单元格、数值、单位和脚注。
3. 人工复核通过后生成独立 Markdown 表格知识文件。
4. 写入 `content_type=table`、页码、表号、父文档、复核人与复核日期。

## P1：批量处理

- 低置信 OCR：300 DPI 重渲染，RapidOCR 复识，视觉模型只校对关键段。
- 图示：视觉模型生成图号、摘要、关联条款与关键参数，人工确认后入库。
- 无文本页面：先分类为空白页、封面、表格、图示或正文，避免遗漏。

## P2：低优先级保留

以说明性图示、封面和对问答价值较低的页面为主。保留源文件、页码和预览，不阻塞正文知识库发布。

## 质量门禁

- 表格结构和关键数值抽样准确率不低于 98%。
- OCR 的条款编号、数值、单位、否定词必须人工核验。
- 图示摘要不得加入原图中不存在的推论。
- 未通过复核的资产继续保留在暂存层，不参与用户检索。
