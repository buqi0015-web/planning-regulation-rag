数据集生成前执行以下质量门禁：

- 固定 100 题，不允许重复问题。
- 检查中文查询是否出现乱码。
- 验证每个标注法规、条款和复杂资产确实存在于正式索引。
- 每题记录类别、难度和一个或多个标准证据。
- 测试集冻结后，基线与迭代使用完全相同的问题和标注。

## 4. 本轮迭代策略

本轮只修改 Query 理解和业务排序，没有更换 Embedding、修改分块或调整测试集：

1. 从 Query 中提取法规名称和标准条款号。
2. 对法规名称精确匹配结果增加权重。
3. 对条款号精确匹配结果增加权重。
4. 将“照度值、间距系数、长高比、标准号、实施日期”等加入表格意图。
5. 将“基准面、计算起点、扫掠角、建模、复杂形体”等加入图示意图。

## 6. 剩余 Bad Case

迭代后 Top-5 失败题从 48 道降至 16 道。主要问题为：

- **解析与分块质量：** 公共建筑节能、住宅设计、旧版规划设计通则等文档存在 OCR 噪声或条款内容被错误归入其他片段，导致正确条款未进入候选集。
- **同规范相邻条款干扰：** “基本原则、基本规定、适用范围”等表达相近，语义检索容易命中同一规范内的相邻条款。
- **图示召回遗漏：** “复杂建筑形体合理简化”仍未召回对应图示，需要为图示增加同义标签或独立 Caption Embedding。
- **测试集覆盖不足：** 当前正式 v1 是检索评测集，尚未包含无答案拒答、版本冲突和完整回答质量的自动评分。

## 7. 下一轮计划

优先级按预期收益和风险排序：

1. 修复高频失败文档的 OCR、目录污染和条款边界，重新建立索引。
2. 为法规名、条款号建立结构化精确检索通道，而不是只依赖排序乘权。
3. 为表格和图示补充规范名称、关联条款、同义标签和结构化字段。
4. 增加 20 道无答案、版本冲突和错地域题，正式评估拒答准确性与错误依据率。
5. 对回答质量测试集执行双人复核，评估 Faithfulness、引用正确性、答案完整性、数字准确性与拒答准确性。
6. 在扩展测试集上对 Cross-Encoder 进行对照实验，验证 nDCG、MRR 与延迟收益后再决定是否接入。

## 8. 回答质量测试状态

已运行 20 道回答质量题并固化系统输出，文件为：

`data/eval/reports/formal_answer_review_v1_generated.csv`

测试题包含 5 道正文题、5 道表格题、2 道图示题、2 道多证据题，以及 6 道应拒答或冲突题。当前尚未执行双人正式评分，因此不将其包装为回答准确率。

初步检查发现：

- 6 道应拒答或冲突题中，4 道明确表达证据不足或无法判断。
- “某住宅项目一定能够通过日照审查”和“密云区某控规地块最终容积率”仍返回了无关证据摘要，没有正确拒答。
- 当前拒答逻辑仅在没有检索结果时触发；只要召回到弱相关材料，就可能过度回答。

这表明下一轮必须增加相关性阈值、答案前证据充分性判断和拒答专项评测。

## 10. 评测边界

- 当前指标只证明检索链路表现，不等于回答准确率。
- 条款定位题占 40%，总体指标需结合分类指标解读。
- 复杂资产和多证据样本量仍较小。
- 测试集标准证据已通过程序校验，但正式生产验收仍需规划业务专家复核。
